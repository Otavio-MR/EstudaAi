# 📚 EstudaAi

O **EstudaAi** é um aplicativo mobile desenvolvido com o objetivo de auxiliar estudantes na preparação para o **ENEM**, **Vestibulares** e **Concursos Públicos**, reunindo conteúdos, tópicos mais recorrentes e materiais de estudo em uma única plataforma.

Projeto desenvolvido para as disciplinas de **Construção de Aplicações para Dispositivos Móveis (CADM)** e **Gerência de Projetos de Software (GPS)** do **Instituto Federal do Paraná (IFPR)**.

---

## 🎯 Objetivo

Oferecer aos estudantes uma plataforma simples e organizada para encontrar conteúdos e materiais de estudo, facilitando a preparação para provas e avaliações de forma acessível e eficiente.

---

## 📱 Plataforma

* Aplicativo Mobile
* Desenvolvido com React Native e Expo

---

## 🚀 Funcionalidades

* Seleção entre categorias de estudo:

  * ENEM
  * Vestibular
  * Concursos Públicos

* Organização dos conteúdos por matérias.

* Exibição de:

  * Resumos das matérias;
  * Tópicos que mais caem nas provas;
  * Links para sites de estudo;
  * Apostilas;
  * Videoaulas.

* Sistema de favoritos para salvar conteúdos em estudo.
